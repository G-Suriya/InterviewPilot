# InterviewPilot (Apply Automagic)

Auto-apply to jobs with tailored resumes and practice with AI mock interviews.

## Features
- **Job Matching & Scraper**: Real-time job search across multiple portals with salary, role, and location filters.
- **Tailored Resumes**: Customized applications tuned to job descriptions.
- **AI Mock Interviews**: Voice-based practice and scoring for matched roles.
- **Application Tracker**: Live application and status monitoring.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```sh
npm install
```

### Development
```sh
npm run dev
```

### Build
```sh
npm run build
```
